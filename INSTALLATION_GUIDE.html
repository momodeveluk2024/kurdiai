Mark-L One-Click Installer

Your Personal AI Assistant - Simple Setup in Minutes

🚀 What is Mark-L?

Mark-L is a personal AI assistant that can:

🎤 Voice Control Real-time voice conversation in multiple languages
💻 System Control Launch apps, manage windows, adjust settings by voice
👁️ Visual Awareness See and understand your screen
🧠 Persistent Memory Remembers conversations across sessions
🔍 Web Search Search the internet and get real-time information
📊 System Monitoring Track CPU, RAM, GPU, and temperature

📋 What You'll Need

1
Gemini API Key (FREE)

Before installing, get your free API key:

  1. Go to https://makersuite.google.com/app/apikey
  2. Sign in with your Google account
  3. Click "Create API Key"
  4. Copy your API key (save it!)
2
Python 3.11 or 3.12

If you don't have Python installed:

  1. Download from python.org
  2. Run the installer
  3. IMPORTANT: Check "Add Python to PATH"
  4. Click "Install Now"
⚠️ Important: If you don't check "Add Python to PATH", the installer won't work!
3
Working Microphone

Ensure your microphone is connected and set as the default recording device in Windows Sound Settings.

⚡ Quick Installation

📁 Installation Files:
  • INSTALL_AND_RUN.bat - Complete installer (run this first!)
  • RUN_MARK_L.bat - Quick launcher (use after installation)
  • Create_Desktop_Shortcut.bat - Add shortcut to desktop
  • SETUP_GUIDE.txt - Detailed text guide
1
Run the Installer

Double-click INSTALL_AND_RUN.bat

⚠️ Windows may show a warning: This is normal! Click "Run" or "Yes" to continue.

The installer will automatically:

  • Download Mark-L
  • Install all required dependencies
  • Set up configuration
  • Prompt for your API key
  • Launch Mark-L
2
Enter Your API Key

When prompted, paste your Gemini API key and press Enter.

3
Wait for Installation

This may take 5-10 minutes. You'll see progress messages as it installs dependencies.

✅ Installation Complete!

Mark-L will start automatically. Try speaking to it!

🎯 Using Mark-L

First Run

After installation, Mark-L will start automatically. A setup wizard will help you configure basic settings.

Future Runs

To run Mark-L again, simply double-click:

  • RUN_MARK_L.bat in the Mark-L folder, OR
  • The Mark-L shortcut on your desktop (if you created one)
Example Commands

Try these voice commands:

  • "Open notepad" - Launch applications
  • "What time is it?" - Get information
  • "Search for Python tutorials" - Web search
  • "Check CPU temperature" - System monitoring
  • "Remind me to call Mom at 5pm" - Set reminders
  • "Read what's on my screen" - Screen awareness

🔧 Optional Enhancements

Create Desktop Shortcut

Run Create_Desktop_Shortcut.bat to add a Mark-L icon to your desktop for easy access.

❓ Troubleshooting

Problem: "Python is not recognized"
Solution: Reinstall Python and check "Add Python to PATH"
Problem: "No module named 'xxx'"
Solution: Run INSTALL_AND_RUN.bat again
Problem: Microphone not working
Solution: Check microphone settings in Windows → ensure it's set as default
Problem: Mark-L won't start
Solution: Ensure api_keys.json exists in the config folder, try re-running installer
