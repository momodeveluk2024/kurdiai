# 🤖 Mark-L One-Click Installer

**A complete, automated installation package for Mark-L - Your Personal AI Assistant**

This package makes it incredibly easy for anyone (even non-technical users!) to install and run Mark-L on Windows.

---

## 🎯 What This Does

This one-click installer handles EVERYTHING automatically:

- ✅ Downloads Mark-L from GitHub
- ✅ Checks for Python installation
- ✅ Installs all Python dependencies
- ✅ Sets up configuration files
- ✅ Prompts for API key setup
- ✅ Creates desktop shortcuts (optional)
- ✅ Launches Mark-L

---

## 🚀 Quick Start (3 Simple Steps)

### Step 1: Get Your Free API Key
1. Go to: **https://makersuite.google.com/app/apikey**
2. Sign in with Google
3. Click "Create API Key"
4. **Copy and save your API key** (you'll need it!)

### Step 2: Install Python (if needed)
1. Download from: **https://www.python.org/downloads/**
2. Run installer
3. **⚠️ IMPORTANT:** Check "Add Python to PATH"
4. Click "Install Now"

### Step 3: Run the Installer
1. Double-click: **`INSTALL_AND_RUN.bat`**
2. Wait for automatic installation (5-10 minutes)
3. Paste your API key when prompted
4. **Done!** Mark-L will start automatically

## ❓ Troubleshooting

### Problem: "Python is not recognized"
**Solution:** Python wasn't added to PATH during installation
- Reinstall Python
- **Check "Add Python to PATH"** during installation

### Problem: "No module named 'xxx'"
**Solution:** Dependencies not installed
- Run `INSTALL_AND_RUN.bat` again

### Problem: Microphone not working
**Solution:** Check microphone settings
- Go to Windows Sound Settings
- Ensure microphone is connected and set as default

### Problem: Mark-L won't start
**Solution:**
- Ensure `api_keys.json` exists in `config` folder
- Try running `INSTALL_AND_RUN.bat` again
